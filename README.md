# PBI-TRAINING-1
## PBI SALES ANALYSIS DASHBOARD (2020-2022)
### PROJECT OVERVIEW
THIS PROJECT FOCUSES ON ANALYZING SALES DATA FROM 2020,2021,2022 USING MICROSOFT POWER BI .the objective is to understand sales performance,customer information,and regional sales trends through interactive visualization.
### OBJECTIVES
- analyze sales data across multiple years.
- understand product performance
- analyze customer and salesperson information.
- explore sales performance across different locations.
- compare sales results with budget data.
- create an interactive dashboard to support business decisions.
  ### DATASET DESCRIPTION
  THE dataset contains the following tables :
  1. ** 2020 sales ** - sales transactions for 2020
  2. ** 2021 sales ** - sales transcations for 2021
  3. ** 2022 sales ** - sales transcations for 2022
