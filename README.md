# PBI-TRAINING-1
## PBI SALES ANALYSIS DASHBOARD (2020-2022)
### PROJECT OVERVIEW
THIS PROJECT FOCUSES ON ANALYZING SALES DATA FROM 2020,2021,2022 USING MICROSOFT POWER BI .the objective is to understand sales performance,customer information,and regional sales trends through interactive visualization.
### OBJECTIVES
- analyze sales data across multiple years.
- understand product performance
- analyze customer and salesperson information.
- explore sales performance across different locations.
- compare sales results with budget data.
- create an interactive dashboard to support business decisions.
  ### DATASET DESCRIPTION
  THE dataset contains the following tables :
  1. **2020 sales** - sales transactions for 2020
  2. **2021 sales** - sales transcations for 2021
  3. **2022 sales** - sales transcations for 2022
  4. **products** -product name,costs,prices,discount, and taxes
  5. **locations** -location details,states,population, and geographical information.
  6. **customers** -customer ids and customer names
  7. **sales person** - salesperson ids and names
  ### TOOLS AND TECHNOLOGIES
  - microsoft power bi
  - power query
  - dax (data analysis expressions)
  - data ,odelling
  - excel
  ### project workflow
  - import the excel dataset into power bi
  - clean and transform the data using power query
  - combine the yearly sales tables where appropriate
  - create relationship between sales and lookup tables
  - create dax measures for sales analysis
  - design interactive charts ,cards, and slicers
  - build a dashboard to explore sales performance.
    ### key analysis areas
  - year - wise sales analysis
  - product performance analysis
  - customer analysis
  - salesperson performance
  - location-wise sales analysis
  ### dashboard features
  the dashboard can include :
  - donut chart
  - card
  - line with bar chart
  - total sales ,cost,profit ,profit margin card
    ### expected business benefit
    - identify top- performing product
    - understand sales trends over date.
